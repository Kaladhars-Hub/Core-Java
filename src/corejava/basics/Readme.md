📌 What is Java?

Java is a programming language used to give instructions to computers.

It helps humans write understandable instructions which are later converted into machine-understandable format.

✅ Main Purpose:

Build software applications
Create backend systems
Develop Android apps
Automate tasks
Build enterprise applications

Line-by-Line Code Explanation
🔹 class HelloWorld
class is a container used to organize code
HelloWorld is the class name
File name should also be HelloWorld.java
🔹 public static void main(String[] args)

This is the starting point of Java execution.

public

Allows Java to access this method.

static

Allows execution without creating object.

void

This method does not return anything.

main

Main starting method.

String[] args

Stores command-line arguments.

🔹 System.out.println()
