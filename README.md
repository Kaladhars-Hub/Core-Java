# Core Java Practice

This repository contains my hands-on practice while learning Core Java with Java 17.

I use this repository to practise concepts through small Java programs, examples, and personal notes. The explanations and comments are written to help me understand the code and remember how each concept works.

## Topics Covered

The repository currently includes practice examples and notes for:

- Java fundamentals: introduction, variables, data types, operators, and user input
- Conditional statements and loops
- Arrays
- Strings, StringBuilder, and StringBuffer
- Classes, objects, methods, and constructors
- Object-Oriented Programming:
  - Inheritance
  - Access modifiers
  - Encapsulation
  - Abstraction and abstract classes
  - Interfaces
  - Polymorphism
- Exception handling
- File handling and text files
- Collections Framework:
  - List, Set, Queue, and Map
  - Iterator, Enumeration, and ListIterator
- Lambda expressions
- Multithreading

The repository is updated as I continue learning and practising. The presence of an example means I have practised that topic; it does not mean I have mastered every part of it.

## Repository Structure

```
src/
├── basics/                  # Java fundamentals, arrays, strings, loops, files, etc.
├── OOPS/                    # Object-oriented programming concepts
├── Collections/             # List, Set, Queue, Map, and iterators
├── Lambdas/                 # Lambda expression examples
├── MultiThreading/          # Multithreading examples
└── StringBuilder_StringBuffer/
                            # StringBuilder and StringBuffer examples
```

Some folders also contain Markdown notes explaining concepts and code examples.

## Tools Used

- Java 17
- IntelliJ IDEA
- Git and GitHub

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Open the Java class you want to practise.
4. Run the class that contains a `main()` method.
